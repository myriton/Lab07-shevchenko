## Что изучено
- Индексация массивов начинается с нуля. Первый элемент имеет индекс **0**, а последний — **Length - 1**. Обращение к несуществующему индексу вызывает ошибку
- Для изменения элементов массива нужен цикл **for**, а не **foreach**
- **foreach** удобен, когда нужны только значения, а не их позиции. Через **foreach** можно только читать значения, так как он не предоставляет доступа к индексу
